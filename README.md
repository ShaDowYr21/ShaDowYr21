## How I work

1. Define the observable contract before implementation.

3. Verify outcomes independently instead of trusting implementation shape.
4. Keep fixtures deterministic, reproducible, and hard for the right reasons.
5. Preserve owner approval for factual, financial, credential, and final-submission decisions.
